## API Docs
- Developers > API Explorer > Authentication [Authentication](https://docs.cobre.com/authentication-25933208e0.md): Use this endpoint to generate the access credentials required to call any Cobre API. Exchange your API credentials for a short-lived token, then pass it in the Authorization header on every subsequent request to ensure secure and consistent access across environments.
- Developers > API Explorer > Accounts [Create or Connect an Account](https://docs.cobre.com/create-or-connect-an-account-25933209e0.md): This endpoint is the single entry point for registering any account on Cobre. The behavior is driven by the `action` field in the request body:
- Developers > API Explorer > Accounts [Obtain all Accounts](https://docs.cobre.com/obtain-all-accounts-25933210e0.md): Retrieve a full list of Cobre Balances (Virtual Balances, Virtual Balance Accounts)  and Connect Accounts available to your organization for operational visibility and reconciliation. Use pagination and filters to efficiently sync balances into your internal systems, especially when running reporting or monitoring workflows.
- Developers > API Explorer > Accounts [Obtain one Account](https://docs.cobre.com/obtain-one-account-25933211e0.md): Retrieve a single Cobre Balance (Virtual Balance, Virtual Balance Account) or Connect Account by its identifier to validate configuration, inspect status, or confirm details prior to executing sensitive actions such as money movements or counterparty linkage.
- Developers > API Explorer > Accounts [Update an Account](https://docs.cobre.com/update-an-account-25933212e0.md): This endpoint allows Cobre Platform users to update an existing Cobre Balance (Virtual Balance, Virtual Balance Account) or Connect Account. It facilitates modifying the information of a previously created account within our ecosystem, ensuring consistency and control in balances and accounts management.
- Developers > API Explorer > Accounts [Close a Cobre Balance](https://docs.cobre.com/close-a-cobre-balance-25933214e0.md): This endpoint close a Cobre Balance (Virtual Account Balances) in Mexico. 
- Developers > API Explorer > Accounts [Obtain one Account Transactions](https://docs.cobre.com/obtain-one-account-transactions-25933215e0.md): This endpoint allows you to retrieve all transactions for a given Cobre Balance (Virtual Balance, Virtual Balance Account) or Connect Account. A transaction reflects a movement (credit or debit) that has occurred in your account. 
- Developers > API Explorer > Accounts [Obtain one Transaction](https://docs.cobre.com/obtain-one-transaction-25933216e0.md): This endpoint allows you to retrieve one specific transaction from any of the Cobre Balances (Virtual Balances, Virtual Balances Accounts) or Connect Accounts. A transaction reflects a movement (credit or debit) that has occurred in your account. 
- Developers > API Explorer > Accounts [Obtain all Transactions](https://docs.cobre.com/obtain-all-transactions-25933213e0.md): This endpoint allows you to retrieve all transactions from all Cobre Balances (Virtual Balance, Virtual Balance Account) and Connect Accounts. A transaction reflects a movement (credit or debit) that has occurred in your account. 
- Developers > API Explorer > Accounts [Obtain Account Daily Balance History](https://docs.cobre.com/obtain-account-daily-balance-history-25933217e0.md): This endpoint allows users to retrieve the **historical balance** of a **Virtual Balance account (Cobre Balance)**.
- Developers > API Explorer > Accounts [Assign or Change Primary Account](https://docs.cobre.com/assign-or-change-primary-account-25933218e0.md): This enpoint allows assigning or changing a primary account to an existing Cobre Balance (Virtual Balance or Virtual Balance Account). 
- Developers > API Explorer > Accounts [Unlinking Primary Account](https://docs.cobre.com/unlinking-primary-account-25933219e0.md): This enpoint allows unlinking a primary account from a secondary account. 
- Developers > API Explorer > Account Verifications [Create an Account Verification](https://docs.cobre.com/create-an-account-verification-25933220e0.md): Account verification consists of comparing the information entered by the user against the data registered at financial institutions.
- Developers > API Explorer > Account Verifications [Obtain one Account Verification](https://docs.cobre.com/obtain-one-account-verification-27088943e0.md): This endpoint returns all account verifications requested.
- Developers > API Explorer > Account Verifications [Obtain all Account Verifications](https://docs.cobre.com/obtain-all-account-verifications-25933221e0.md): This endpoint returns all account verifications requested.
- Developers > API Explorer > Account References [Create an Account Reference](https://docs.cobre.com/create-an-account-reference-26104719e0.md): This enpoint allows the creation of account references. 
- Developers > API Explorer > Account References [List one Account Reference](https://docs.cobre.com/list-one-account-reference-26105126e0.md): This endpoint retrieves one specific Account Reference.
- Developers > API Explorer > Account References [List all Account References](https://docs.cobre.com/list-all-account-references-26105105e0.md): This endpoint retrieves all Account References.
- Developers > API Explorer > Account References [Delete an Account Reference](https://docs.cobre.com/delete-an-account-reference-26105166e0.md): This endpoint deletes an Account Reference.
- Developers > API Explorer > Account References [Generate a Certificate for your Account Reference](https://docs.cobre.com/generate-a-certificate-for-your-account-reference-34569214e0.md): Generate a PDF certificate that includes all the information needed by your payers to initiate a transfer to your account references, along with a legal text that lets your payers know the role of Cobre as your collection provider.
- Developers > API Explorer > Cobre Keys [Create a Key](https://docs.cobre.com/create-a-key-25933247e0.md): This endpoint allows the creation of Cobre keys, which will then be assigned a key_value. This value will be registered in the key management and in the Bre-B platform.
- Developers > API Explorer > Cobre Keys [Obtain all Keys](https://docs.cobre.com/obtain-all-keys-25933248e0.md): This endpoint **returns all keys** associated with the client's Cobre Balance accounts.
- Developers > API Explorer > Cobre Keys [Obtain one Key](https://docs.cobre.com/obtain-one-key-25933249e0.md): This endpoint **returns one specific key** associated with the client's Cobre Balance account.
- Developers > API Explorer > Cobre Keys [Cancel a Key](https://docs.cobre.com/cancel-a-key-25933250e0.md): This endpoint allows the **cancellation** of a Cobre key.
- Developers > API Explorer > Cobre Keys [Block or Reactivate Keys](https://docs.cobre.com/block-or-reactivate-keys-25933251e0.md): This endpoint **allows actions** to be performed on a Cobre key.
- Developers > API Explorer > Counterparties > Account Debit Registration [Register a Counterparty for Direct Debit](https://docs.cobre.com/register-a-counterparty-for-direct-debit-25933233e0.md): ## Direct Debit Registration API
- Developers > API Explorer > Counterparties > Account Debit Registration [Obtain all Registrations](https://docs.cobre.com/obtain-all-registrations-25933234e0.md): This endpoint will list all your accounts that have been registered into a counterparty.
- Developers > API Explorer > Counterparties > Account Debit Registration [Obtain one Registration](https://docs.cobre.com/obtain-one-registration-25933235e0.md): Retrieve the debit registration given the id.

- Developers > API Explorer > Counterparties [Delete a Counterparty](https://docs.cobre.com/delete-a-counterparty-25933232e0.md): This endpoint will allow you to delete a specific counterparty within the platform.
- Developers > API Explorer > Money Movements [Create a Money Movement](https://docs.cobre.com/create-a-money-movement-25933236e0.md): This endpoint simplifies the initiation of money movement operations. To initiate a movement, only four parameters are necessary: `source`, `destination`, `metadata`, and `amount`. For enhanced tracking, an optional fifth parameter, `external_id`, can be provided.
